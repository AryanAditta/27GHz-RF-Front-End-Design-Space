# Cascode Low-Noise Amplifier (Cascode LNA)

Planned 27 GHz SiGe HBT cascode-LNA extension for the common RF front-end design-space project.

This branch will combine low-noise matching and stability constraints with the gain and isolation characteristics of a cascode topology. Parameter schema, validated schematics and dataset records will be added only after the topology is finalized rather than inferred prematurely.
