# Common-Emitter Low-Noise Amplifier (CE LNA)

27 GHz low-noise common-emitter SiGe HBT branch with inductive emitter degeneration and noise/gain/stability-oriented matching.

## Planned design-space variables

Bias voltage, transistor multiplier, emitter-degeneration inductance, collector RF choke and input/output matching-network values are varied systematically.

## Characterization focus

The LNA workflow emphasizes noise figure, minimum noise figure, gain, matching and stability before large-signal linearity characterization. Input and output matching are iterated because the device is bilateral and changes at one port can affect the other.

Dataset expansion is in progress and will be added after the validation workflow is finalized.
