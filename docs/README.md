# Project Documentation

Shared technical notes, workflow descriptions, dataset conventions and reproducibility information for the 27 GHz RF front-end design-space project belong here.

Topology-specific material should stay under `circuits/`; released tables under `data/`; reusable analysis code under `scripts/`.

As the project matures, this directory can hold items such as:

- simulation and extraction workflow notes
- naming and dataset conventions
- validation criteria
- tool/version information
- design-space methodology
- release notes for validated dataset snapshots
