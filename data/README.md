# Dataset Status

A structured RF design-space dataset is being generated for the circuit families documented in this repository.

Each sample represents one circuit configuration and its validated simulation response:

```text
circuit parameters -> simulation / post-processing -> RF performance labels -> dataset row
```

The dataset includes topology-specific design variables and RF performance metrics derived from the validated simulation workflow.

## Availability

The underlying dataset is **private and is not released in this public repository**.

This directory is retained only to document the dataset-generation component of the project and its relationship to the public circuit/workflow material.

Public repository content may include selected schematics, figures, methodology notes and non-sensitive post-processing code, but not the raw or curated design tables.
